Vidya Sethu is an admin dashboard for managing student scholarship applications from start to finish.

How it works:

A student applies for a scholarship — their details (CGPA, category, income) are checked against the scholarship's eligibility rules.
An admin verifies the application (documents, eligibility).
The admin approves or rejects it with one click.
Each application shows its progress on a simple tracker: Submitted → Verification → Decision.
Admins can also track scholarship seats, budgets, and applicant numbers, and close a scholarship once it's full or past deadline.
All data can be searched, filtered, and exported as a CSV report anytime.
